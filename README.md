# Traveller – Mini Travel Experience Platform
A full-stack web application where users can create and explore travel experiences. Users can sign up, publish listings, and browse experiences shared by others through a simple and responsive interface.

## Live Demo - https://traveller-two-gamma.vercel.app/
⚠️ Server Wake-Up Notice ⚠️

This app is hosted on Render's free tier.
If the site has been inactive for a while, the server may take up to a minute to start when you first visit.

## Tech Stack
- Frontend: React.js, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Other: JWT, Cloudinary

## Features
- User registration and login
- Create travel experience listings
- Upload images
- Browse public feed
- Like listings
- User dashboard
- Edit/Delete listings

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
- Image Storage: Cloudinary

## Installation
#### clone repo
- git clone https://github.com/WH1SPER-117/Traveller.git

#### install dependencies
- npm install

#### start backend
- npm run server

#### start frontend
- npm start
