# Traveller – Mini Travel Experience Platform

## Tech Stack
Node.js
Express.js
MongoDB
Next.js
Tailwind CSS
Cloudinary
JWT Authentication

## Features
User registration and login
Create travel experience listings
Upload images
Browse public feed
Like listings
User dashboard
Edit/Delete listings

## Deployment
Frontend: Vercel
Backend: Render
Database: MongoDB Atlas
Image Storage: Cloudinary
